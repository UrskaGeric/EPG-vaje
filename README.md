# Evolucijska in populacijska genetika: vaje

Navodila za vaje pri predmetu Evolucijska in populacijska genetika (EPG).

**Spletna stran: <https://urskageric.github.io/EPG-vaje/>**

## Vsebina repozitorija

Repozitorij vsebuje renderirano spletno knjigo (Quarto book).

```text
EPG-vaje/
├── index.html                  # domača stran knjige
├── E1_nadzor_razlicic/         # vaja 1: navodila in slike
├── literatura/                 # članki (PDF, open access)
├── site_libs/, search.json     # tehnične datoteke knjige (meni, iskalnik)
└── README.md
```

| Vaja | Tema | |
|---|---|---|
| 0 | Uvod v R, RStudio in Quarto | kmalu |
| 1 | Nadzor različic z Gitom in GitHubom | [odpri](https://urskageric.github.io/EPG-vaje/E1_nadzor_razlicic/E1_nadzor_razlicic.html) |
| 2 | SNP-ji in PLINK | kmalu |
| 3 | Genetska raznolikost in diferenciacija | kmalu |
| 4 | Populacijska struktura | kmalu |
| 5 | Sorodnost, inbriding in ROH | kmalu |

## Za študente

Knjigo odprete tudi brez interneta z dvoklikom na `index.html`.

```bash
git clone https://github.com/UrskaGeric/EPG-vaje.git
cd EPG-vaje
git pull        # pred vsako vajo
```

Tega repozitorija ne urejajte. Svoje skripte shranjujte v svoj repozitorij `EPG-2026-priimek` (navodila so v vaji 1).
